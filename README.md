# stylometry — Лаб. работа №1

Расчёт вероятного автора текста методом стилометрии. Три страницы (лента / добавление / плитка)
работают с коллекцией `StylometrySample` — эталонные образцы текстов известных авторов со
стилометрическими маркерами (средняя длина предложения, частота союзов).

## Визуальная тема

Интерфейс выполнен в редакционном стиле, вдохновлённом «Культура.РФ»: светлая основа,
много свободного пространства, графитовая типографика и красный акцент. Цветовая палитра
ориентирована на фирменные цвета, указанные в брендбуке PRO.Культура.РФ.

Медиафайлы в проект не входят: изображения и видео загружаются пользователем самостоятельно
в MinIO. Приложение обращается к объектам по ключам `images/<author>.webp` и
`videos/<author>.mp4`.
